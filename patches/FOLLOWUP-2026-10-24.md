## Changes

- `device/xiaomi/virgo/0012-label-adreno-memalloc-dependency.patch`: label
  libmemalloc.so as a same-process HAL dependency. The generic vendor label
  prevented cold app processes from loading it in Enforcing mode. Device
  file-context configuration was updated and restorecon verified the label.
- `frameworks/native/0001-bridge-legacy-powermanager-wakelocks.patch`: restore
  Android 4.4's C++ IPowerManager entry point and vtable for libmm-abl.so. Calls
  forward to Android 14's generated Binder interface, allowing mm-pp-daemon to
  run instead of failing its linker. No old Binder wire protocol is used.
- `hardware/qcom-caf/wlan/0001-accept-legacy-single-radio-link-stats.patch`: accept
  single-radio firmware replies without later NUM_RADIOS and TS_DUTY_CYCLE
  attributes. Other required fields remain validated.
- `system/netd/0001-restore-legacy-qtaguid-hooks.patch`: install xt_qtaguid owner
  accounting hooks when ro.kernel.ebpf.supported=false. The modern BPF backend
  remains the default without that explicit opt-out.
- `packages/modules/Connectivity/0002-restore-legacy-qtaguid-statistics.patch`:
  read cumulative legacy counters, bypass unavailable BPF maps, avoid adding
  cumulative polls repeatedly, and handle foreground changes and UID deletion
  through the legacy control interface. Dumping an unavailable interface map no
  longer throws. Regression cases cover missing maps and cumulative polls.
- `device/xiaomi/virgo/0015-allow-legacy-netstats-control.patch`: allow
  system_server to use the specific proc_qtaguid_ctrl file for UID operations.
- `vendor/qcom/opensource/power/0001-use-msm8974-legacy-perflock-hints.patch`:
  send launch/interaction requests through perf_lock_acq/rel, which the shipped
  client provides. Deduplicate launch enables; ignore unmatched disables.
- `packages/apps/Settings/0004-handle-optional-process-power-data.patch`: avoid
  querying absent process-state power columns in historical BatteryUsageStats.
- `device/xiaomi/virgo/0013-add-manual-legacy-compat-probe.patch`: add a manual
  diagnostic module, not a PRODUCT_PACKAGES entry, for real wake locks/perflocks.
- `device/xiaomi/virgo/0014-record-existing-350dpi-preference.patch`: record the
  pre-existing local density so the patch series replays. This repair did not
  change the density preference.
