# Wi-Fi 初始化失败修复

## 故障证据

来源为持续 cache 日志修复后的真实 Enforcing 开机日志：
`device/xiaomi/virgo/tests/cache-logger-20261025/after/{boot_log.txt,dmesg.txt}`。

- Wi-Fi HAL：`Failed to write wlan fw path param: No such device`、`Failed to change firmware mode`，框架无法创建 STA iface。
- `wcnss_service` 缺少 `/vendor/etc/wifi/WCNSS_qcom_cfg.ini`。
- modem 分区已经由 fstab 挂载到 `/firmware`，但使用了通用 `vfat` SELinux 标签。ueventd 被拒绝 search，无法读取 `/firmware/image/adsp.mdt` 和 `mba.mdt`；qmuxd 没有可用 modem 连接，WCNSS 读取 MAC 的 QMI 调用一直等待。
- init.target.rc 又尝试把同一分区挂到 `/firmware`，发生 mounton AVC。

## 修复

`device/xiaomi/msm8974-common/`：

1. fstab 的 modem 挂载增加 `context=u:object_r:firmware_file:s0`，使用现有专用类型及读取规则。
2. init.target.rc 删除重复挂载命令，以 fstab 为唯一挂载来源。
3. 将现有 WCNSS_qcom_cfg.ini 同时打包到 `/vendor/etc/wifi/`，符合当前 WCNSS 服务的源文件路径。

补丁：`device/xiaomi/virgo/patches/device/xiaomi/msm8974-common/0006-label-firmware-mount-and-package-wcnss-config.patch`。
没有为通用 vfat 类型增加访问权限，也没有切换到 Permissive。

## 验证

```sh
export OUT_DIR=/run/media/root/c309382c-cda1-4153-ad35-de1784b9715e/virgo-out
source build/envsetup.sh
lunch lineage_virgo-ap2a-eng
m -j8 fstab.qcom init.target.rc "$OUT_DIR/target/product/virgo/system/vendor/etc/wifi/WCNSS_qcom_cfg.ini"
```

设备备份、部署 manifest、回读校验及测试证据保存在 `device/xiaomi/virgo/tests/wifi-20261025/`。
原有 fstab 和 init.target.rc 已备份；WCNSS 的新目标文件原先不存在。
临时测试 probe 开机后启用 Wi-Fi、请求扫描并采集 status、scan results、dumpsys、logcat、dmesg，然后自动返回 Recovery。

TWRP 使用自己的旧策略，不认识 firmware_file 上下文，因而不能用 Recovery 内的挂载测试代替 Android 系统策略验证；系统已有策略包含该类型。
